# ROS2_WLKATA
This repository contains all ROS 2 packages, code, configuration files, and tutorials for WLKATA robotic products, including Mirobot, MT4, Haro, Brave, MarchX, and more.

## ROS2 Mirobot 
Please visit [ROS2 Mirobot](https://github.com/Eagle-Creative/ROS2-Jazzy-Mirobot-Interface) for ROS 2 interface for controlling the WLKATA Mirobot with support for joint control, Cartesian positioning, and flexible configuration.
